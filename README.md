# Kotlin Chinese

Kotlin 中文语法糖实验工程，目标是用接近中文表达的 API 包装 Kotlin 常用能力。

## 📖 项目简介

本项目是一个创新的 Kotlin 语言扩展库，通过提供中文命名的类型别名、函数和 DSL（领域特定语言），让开发者能够使用更贴近中文思维的方式编写 Kotlin 代码。这不仅降低了编程门槛，也为中文开发者提供了更加友好的编程体验。

### 💡 为什么需要这个项目？

- **降低学习曲线**: 对于中文母语者来说，使用中文API可以更快理解编程概念
- **提高代码可读性**: 在团队内部或教育场景中，中文表达可能更直观
- **文化包容性**: 为非英语母语的开发者提供更友好的编程体验

## ✨ 主要特性

- **中文类型别名**: 如 `字符串`、`整数`、`布尔`、`列表` 等
- **中文集合操作**: 如 `过滤`、`映射`、`排序`、`分组` 等 
- **中文字符串处理**: 如 `包含`、`替换全部`、`切分`、`去空白` 等
- **中文控制流**: 如 `如果`、`当`、`循环`、`重复` 等
- **中文异常处理**: 如 `尝试`、`成功时`、`失败时`、`重试` 等
- **中文DSL构建器**: 支持用中文方式构建类和对象
- **完整测试覆盖**: 所有功能都有详细的单元测试验证
- **零性能损耗**: 基于Kotlin inline函数和类型别名，无额外运行时开销

## 🚀 快速开始

### 添加依赖

在您的 `build.gradle.kts` 文件中添加：

```kotlin
dependencies {
    implementation(project(":kotlin-zh"))
}
```

### 基本使用示例

```kotlin
import com.ohuang.kotlin_zh.stable.*

// 使用中文类型别名
val 文本: 字符串 = "你好世界"
val 数值: 整数 = 42
val 开关: 布尔 = true

// 使用中文字符串方法
val 你好:字符串 ="你好,世界!Hello, World!"
你好.非空白() // 检查是否非空白
你好.包含("世界") // 检查是否包含指定内容
你好.去空白() // 去除首尾空白
你好.转小写() // 转换为小写

// 使用中文集合操作
val 数据 = 列出(1, 2, 3, 4, 5)
数据.过滤 { it > 2 }      // 过滤元素
数据.映射 { it * 2 }       // 转换元素
数据.排序()                // 排序
数据.数量                  // 获取数量

// 使用中文集合 (Set)
val 唯一数据 = 集(1, 2, 3, 2, 1)  // 自动去重，结果为 {1, 2, 3}
val 可变集合 = 可变集("a", "b")
可变集合.添加("c")            // 添加元素

// 集合运算
val 集合A = 集(1, 2, 3, 4, 5)
val 集合B = 集(3, 4, 5, 6, 7)
集合A.与(集合B)     // 交集: {3, 4, 5}
集合A.或(集合B)     // 并集: {1, 2, 3, 4, 5, 6, 7}
集合A.差集(集合B)   // 差集: {1, 2}
```

### 高级示例

```kotlin
// 控制流示例
如果(数值 > 0) {
    打印行("正数")
} 否则 {
    打印行("非正数")
}

// 异常处理示例
尝试 {
    val 结果 = 10 / 0
} 成功时 { 值 ->
    打印行("计算结果: $值")
} 失败时 { 异常 ->
    打印行("发生错误: ${异常.message}")
}

// DSL构建器示例
val 用户类 = 定义类 {
    属性("名字", "张三")
    属性("年龄", 25)
    
    方法("介绍") {
        返回("我叫${取<字符串>("名字")}，今年${取<整数>("年龄")}岁")
    }
}

val 用户 = 用户类.调用类()
打印行(用户.调用方法("介绍")) // "我叫张三，今年25岁"
```

## ❓ 常见问题

### Q: 中文编码问题如何处理？
A: 确保项目文件使用UTF-8编码，现代IDE都很好地支持Unicode标识符。

### Q: 性能会有影响吗？  
A: 中文扩展大多是inline函数或直接委托给原生API，性能影响可以忽略不计。

### Q: 能否与现有Kotlin代码混用？
A: 完全可以，中文API只是额外的扩展，不影响原有代码。

### Q: 如何贡献新的中文API？
A: 欢迎提交PR，请遵循现有代码风格并添加相应测试。
